Services fixed-file execution contract (qualification39)

The registered run function takes no params_json or params_file argument. Write the exact scenario JSON to a resource, mount the actual returned FILE URI at /input/params.json, and request outputMounts ["/output"]. Obtain the actual nodepool ID with GetNodePoolContext. Each job is limited to 2 CPUs and 4Gi RAM. Do not install software or PDKs, scale resources, delegate, or launch investigations. Read common_design_envelope.json from the returned output asset; a completed native job is not sufficient proof of a passing domain verdict. Retain failed native status, exit code and logs. A missing engine, deck or model is blocked/not_assessable, not pass. Do not substitute invented technology constants or skip mandatory engines.

Failed Services jobs can omit assets. The source-embedded launcher logs CDE_JSON=<actual persisted envelope> without changing the native worker exit. Recover only this exact native log payload, never reconstruct an envelope.

Native status and verdict are retained verbatim. SERVICES_EXIT_JSON records the original worker exit and effective exit; fail/not_assessable domain verdicts or missing envelopes force nonzero effective exit even if the original worker returned completed/exit 0. No envelope status or verdict is rewritten.
