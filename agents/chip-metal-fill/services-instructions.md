# Services execution

Use only the registered run function. WriteResource takes literal raw UTF-8
JSON, not base64. Mount a unique parameter FILE URI at /input/params.json,
referenced routed DEF/LEF/PDK fill configuration at their declared paths, and
outputMounts ["/output"]. Use GetNodePoolContext's actual ID.
The Services action has no params_json field. Never invent density windows,
layer mappings or fill rules. Missing PDK fill configuration blocks native
qualification. Read common_design_envelope.json, or actual persisted CDE_JSON=
from failed native logs if assets are missing. Framework completion alone is
not native pass or density signoff.
