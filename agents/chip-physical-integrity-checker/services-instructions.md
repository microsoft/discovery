# Services execution

Invoke only the registered run function. Create unique literal raw UTF-8 JSON
with WriteResource; mount the actual file URI at /input/params.json.
Resolve attached PDK resources with GetResourceContext and use its exact
returned URI; never guess directory aliases. Compare Liberty cell identifiers
independent of optional quotation marks; retain genuine unknown-cell failures.
WriteResource does not decode base64. Mount referenced databases, netlists,
libraries and evidence files and use outputMounts ["/output"] plus the actual
GetNodePoolContext ID. The Services action has no params_json field.
Required checks without evidence remain not_assessable. A restricted netlist
check is not full physical signoff. Read common_design_envelope.json from the
returned asset; failed jobs without assets expose their actual persisted
envelope in CDE_JSON= native logs. Preserve every failed attempt.
