## Inventory coverage

- Scenario `files` lists all text shipped in its folder. New unlisted files fail
  validation; source-specific inventories explain why private/large items are
  absent. [assets.json](biopharma/assets.json) and each sibling scenario's asset
  manifest are machine-readable acquisition/integrity records, not authorization.
- SiPhy contains 40 distinct design papers, CMS 14 skincare papers, standalone
  Bookshelf 15 public SCLC papers. These are three different corpora, never one
  common shared shelf. Keep internal regression datasets fixed and separate.
- The offline helper stages these documents and the shared runner into a fresh
  directory. It does not copy virtual environments, installed runtimes, tools,
  old outputs or `.discovery` state, and it does not download assets.
- Public delivery is blocked where no verified approved source exists. A
  null URL is an explicit author task, not a link for an external user to fix.
- Historical screenshots, source extraction diagnostics and previous successful
  runs are not new execution evidence for this package. The private authoring
  source map is maintained separately from distributable content.
