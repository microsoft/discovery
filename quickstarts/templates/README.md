# QuickStart Scenarios templates

Start with **[QuickStart-Template.md](QuickStart-Template.md)**.
It is included in full, byte-for-byte unchanged. This folder contains the
blank template and this README, not a shortened replacement or another format.

Download a copy, then complete it for your own tested scenario. The completed
SiPhy guide is a separate example, not the blank template.

## For scenario owners

1. Use [the original blank template](QuickStart-Template.md) to document the
   scenario you actually ran.
2. Keep the complete model/setup/input/prompt/result/validation information.
   Mark unknowns honestly; do not turn them into N/A or fictional measurements.
3. Put the full completed Markdown beside the scenario README, and its exact
   required input files in that scenario's `files/` folder.
4. Supply the associated skill, if any, without silent edits. The
   [shared runner](../../skills/quickstart-runner/README.md) follows the full
   guide; conflicts with older skill versions must be reconciled explicitly.
5. Provide actual reference outputs and identify public distribution rights.
   Large approved files can be repository-release assets with exact checksums.
